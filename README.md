# NeTotDEDD

Учебные проекты по физике, численные расчёты и визуализация. Использую Python и инструменты ИИ для подготовки материалов и разработки.

## Квантовая физика

[FIZOS_Kvanty](https://github.com/NeTotDEDD/FIZOS_Kvanty) — решения задач к семинарам по квантовой, атомной и ядерной физике на основе задачника Овчинкина.

117 задач за 13 учебных недель: краткая теория, подробные выводы и 33 иллюстрации. Материалы включают указатель задач и пояснения к расхождениям с печатными ответами.

[Открыть материалы](https://github.com/NeTotDEDD/FIZOS_Kvanty#readme) · [Указатель задач](https://github.com/NeTotDEDD/FIZOS_Kvanty/blob/main/TASKS.md)

## Планы

На основе сборника планирую развивать:

- **Численные расчёты на Python** — проверка результатов и построение графиков к решениям.
- **Интерактивные модели** — туннелирование, уровни энергии и спектры излучения с изменяемыми параметрами.
- **Материалы по другим разделам физики** — решения и конспекты с общей навигацией.
